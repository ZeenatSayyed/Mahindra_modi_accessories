ACCESSORIES SITE - HOW TO USE

1. Free hosting (pick one):
   - Netlify Drop: go to app.netlify.com/drop and drag this whole folder in. You get a public link.
   - GitHub Pages: upload these files to a GitHub repo, then Settings > Pages > Deploy from branch.
2. Make a STATIC QR code from that link (for example with qr-code-generator.com or Chrome's "Create QR code").
3. Showroom name, phone numbers and branch map links: open showroom.js in a text editor, change the text between the quotes, save.
4. New cars or accessories: send the new catalogue PDF to Claude and ask it to add it. Each car lives in its own car-*.js file.
5. The PPF video is media/ppf.mp4. Replace the file (same name) to change it.
